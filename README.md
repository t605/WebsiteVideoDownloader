# Video Downloader

A Windows tool, built on [yt-dlp](https://github.com/yt-dlp/yt-dlp), that saves a video in 480p (or only the sound as an MP3)
from a pasted link. Large-text window in English and Russian.

This tool was built for my elderly mother to help her download webinars in Russian.

## Get it

1. Open **Releases** on this GitHub page and download `WebsiteVideoDownloader.zip`.
2. Unzip it into a folder of your own. Do not run it from inside the zip.
3. Double-click `VideoDownloader.bat`. The first start takes a few minutes: it installs Python and what it needs.

Windows 10 or 11 only. The full manual is in `README.txt`.

## Personal use only

Personal use only. Use your own login only. The program does not break copy protection. This is not legal advice.
"Fair use" is a United States rule and does not apply everywhere. What you may save depends on the video, the website and
the law of your country, and it is your own responsibility.
